# personal-finance

Консольное приложение для управления личными финансами. Итоговый проект по дисциплине «Принципы объектно-ориентированного программирования» (МИФИ, SkillFactory).

## Возможности

- Регистрация и вход по логину и паролю, несколько пользователей. Пароль хранится только как хэш PBKDF2 с солью.
- У каждого пользователя свой кошелёк: доходы, расходы, баланс, бюджеты по категориям.
- Сводка: общие доходы и расходы, суммы по категориям, бюджет, потрачено и остаток по каждой категории. Можно выбрать несколько категорий и период, вывести в терминал или в файл.
- Оповещения: превышен бюджет, израсходовано 80% бюджета, расходы превысили доходы, баланс стал нулевым.
- Редактирование: изменить или убрать бюджет, переименовать категорию.
- Переводы между пользователями: расход у отправителя, доход у получателя.
- Данные хранятся в памяти и записываются в файл при выходе, при входе кошелёк загружается из файла.
- Экспорт кошелька в JSON и CSV, импорт снимка из JSON.

## Установка и запуск

Нужны Java 21 и Maven 3.9 или новее. Библиотека Jackson скачивается Maven при сборке.

```bash
mvn package
java -jar target/personal-finance.jar
```

Данные лежат в папке `data/` рядом с местом запуска, другую папку можно передать аргументом: `java -jar target/personal-finance.jar /путь/к/данным`.

## Команды

| Команда | Что делает |
|---|---|
| `register <логин> [пароль]` | регистрация |
| `login <логин> [пароль]` | вход; без пароля в строке он запрашивается отдельно и не отображается |
| `income <сумма> <категория> [заметка]` | добавить доход |
| `expense <сумма> <категория> [заметка]` | добавить расход |
| `budget <категория> <сумма>` | задать или изменить бюджет |
| `budget-remove <категория>` | убрать бюджет |
| `rename <старая> <новая>` | переименовать категорию вместе с операциями и бюджетом |
| `summary [категории...] [--from ГГГГ-ММ-ДД] [--to ГГГГ-ММ-ДД] [--file путь]` | сводка |
| `history` | все операции |
| `transfer <логин> <сумма>` | перевод другому пользователю |
| `export <файл.json\|файл.csv>`, `import <файл.json>` | выгрузка и загрузка |
| `save`, `logout`, `exit` | сохранить, выйти из кошелька, выйти из программы |

Категории из нескольких слов пишутся в кавычках: `expense 3000 "Коммунальные услуги"`.

Пример из задания:

```text
pavel> summary
Общий доход: 63,000.00
Доходы по категориям:
  Бонус: 3,000.00
  Зарплата: 60,000.00
Общие расходы: 8,300.00
Расходы по категориям:
  Еда: 800.00
  Коммунальные услуги: 3,000.00
  Развлечения: 3,000.00
  Такси: 1,500.00
Бюджет по категориям:
  Еда: 4,000.00, потрачено: 800.00, оставшийся бюджет: 3,200.00
  Коммунальные услуги: 2,500.00, потрачено: 3,000.00, оставшийся бюджет: -500.00
  Развлечения: 3,000.00, потрачено: 3,000.00, оставшийся бюджет: 0.00
Баланс: 54,700.00
```

## Архитектура

- `core` - модель (`Wallet`, `Operation`, `User`), сервисы `FinanceService` и `AuthService`, проверка ввода `Validation`, интерфейсы хранилищ `UserRepository` и `WalletRepository`. От файлов и консоли не зависит.
- `infra` - реализации хранилищ на JSON-файлах (Jackson), экспорт в CSV.
- `cli` - разбор команд с поддержкой кавычек, форматирование сумм, цикл команд.
- `App` собирает зависимости вручную.

Суммы хранятся в `BigDecimal` с двумя знаками, чтобы не терять копейки на округлении.
